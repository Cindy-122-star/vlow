# V_LOW 萤火虫任务 Demo

此文件夹是可单独发布的 GitHub Pages 网站。上传本文件夹中的所有内容到一个独立 repository 根目录，确保 `index.html`、`styles.css` 与 `demo.js` 位于根目录。

## 发布步骤

1. 在 GitHub 新建一个 repository，名称建议为 `v_low-firefly-demo`。
2. 将此文件夹内的文件上传至 repository 根目录。
3. 在 repository 的 **Settings → Pages** 中，将发布源设置为 `main` 分支、`/(root)` 目录。
4. 等待 Pages 部署完成后，访问 `https://你的用户名.github.io/v_low-firefly-demo/`。

本网页为静态 Demo，不会自动将答题数据传回问卷平台或数据库。
